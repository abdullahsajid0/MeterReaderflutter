# Getting Support for WattWise

Thank you for using WattWise! Here are the best channels to get help, ask questions, or report problems:

---

## 💬 Community Discussions & Q&A
For general questions, discussions about electricity billing calculations, or help setting up the app:
👉 **[Join GitHub Discussions](https://github.com/abdullahsajid0/MeterReaderflutter/discussions)**

- **Q&A**: Ask questions about how slab forecasting works.
- **Ideas**: Share suggestions for new features before opening a formal issue.
- **Show and Tell**: Share how WattWise helps you monitor your electricity consumption.

---

## 🐛 Bug Reports & Technical Issues
If you encounter a crash, a calculation bug, or an OCR error:
👉 **[Open an Issue](https://github.com/abdullahsajid0/MeterReaderflutter/issues/new/choose)**

Please use the appropriate issue template:
- **Bug Report**: For app crashes or visual glitches.
- **DISCO / Tariff Update**: When a utility portal URL changes or NEPRA updates slab unit rates.
- **Feature Request**: For formal feature proposals.

---

## 🔒 Security Vulnerabilities
If you discover a security issue, please review our [Security Policy](SECURITY.md) to report it privately.
